# FRC KitBot 2026 — REBUILT Season

## Summary

The official [FIRST Robotics Competition](../entities/first-robotics-competition.md) KitBot resource page for the 2026 REBUILT season. The KitBot is a beginner-friendly robot kit included in the FRC Kickoff Kit, built on the [AndyMark](../entities/andymark.md) AM14U6 chassis. It provides a competition-ready baseline platform that rookie and resource-limited teams can build, program, and iterate on. The page hosts build instructions, CAD models (Onshape + STEP), Java code with a walkthrough guide, and an enhancement/iteration brainstorming guide.

## Key claims

- **Chassis**: Built on the [AndyMark](../entities/andymark.md) AM14U6 drivetrain chassis — a well-established FRC swerve/tank-drive platform used across many seasons.
- **Build correction**: The 2026 "Square" KitBot configuration requires cutting 3 inches off each side plate (not 6 inches as originally printed in some instructions).
- **CAD availability**: Full 3D models available in Onshape (browser-based) and as downloadable STEP files — enabling teams to modify and simulate before fabrication.
- **Code**: Java codebase with an accompanying guide explaining the code structure, intended as a learning resource for teams new to FRC programming (WPILib ecosystem).
- **Multilingual documentation**: Build instructions available in English, Chinese, Hebrew, Portuguese, Spanish, and Turkish — reflecting FRC's 30+ country reach.
- **Enhancement guide**: A dedicated document for brainstorming improvements beyond the stock KitBot — encourages teams to iterate rather than start from scratch.
- **Bumper resources**: Includes references to building bumpers in multiple configurations, cross-linked with the Game Manual's bumper rules (§8.4 of [FRC 2026 Game Manual](frc-2026-game-manual.md)).
- **Support**: Teams directed to FIRST Forums for Q&A; staff monitors discussions throughout build and competition season.
