## Summary
Product documentation for Elephant Robotics' [myAGV](../entities/myagv.md) autonomous mobile robot and its compound mobile robot collection (myAGV + arm combos). Affordable educational/research compound mobile manipulators.

## myAGV 2023 Pi specs
- Price: ~$1,498–$1,598
- Processor: Raspberry Pi 4B
- OS: Ubuntu Mate 20.04
- Motors: brushless DC planetary
- Navigation: 2D and 3D mapping + autonomous pathfinding
- Control: gamepad, keyboard, software
- Programming: myBlockly (drag-and-drop) + Python 2/3
- Pre-installed: ROS, OpenCV, QT, VSCode, VNC, SSH
- Cloud: myStudio for firmware updates
- Compatible arms: myCobot 280 Pi, myPallitizer 260, mechArm 270, myArm, ultraArm
