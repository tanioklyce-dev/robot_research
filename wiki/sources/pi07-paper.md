## Summary

**π0.7** — Physical Intelligence's late-2025 successor to [π0](pi-zero-paper.md) (and to the unreleased-but-referenced π0.5, π0.6, and π0.6-MEM). **5B-parameter VLA** = **Gemma3 4B VLM backbone** (incl. 400M vision encoder) + **860M [flow-matching](../concepts/learning/flow-matching.md) action expert** + **MEM-style video history encoder**. The headline contribution is **multimodal context conditioning**: the standard "language instruction" prompt is expanded with **subtask instructions, subgoal images** (generated on the fly by a separate **BAGEL 14B world model**), **episode metadata** (overall speed, quality 1–5, mistake labels), and **control-mode tags** (joint vs end-effector). Trained with each context component randomly dropped, so any subset is available at test time. The bet: **detailed prompts + diverse data = compositional generalization** — letting the model use demonstrations, suboptimal autonomous rollouts (including failures), and non-robot data (egocentric human video + web) without averaging them into mush.

Result: **out-of-the-box** performance on long-horizon dexterous tasks like **operating an espresso machine, folding laundry, taking out trash, folding boxes, and peeling vegetables** — across multiple robot platforms, in unseen environments, with **zero-shot cross-embodiment transfer** and **compositional task generalization** (e.g., loading a sweet potato into an air fryer when neither the air fryer nor the sweet potato appeared in training).

## Key claims

### Architecture (paper §IV + Fig. 2)

- **5B total params** = 4B VLM backbone (Gemma3) + 860M action expert.
- **VLM backbone**: [Gemma3 4B](https://arxiv.org/abs/2503.19786) (Google, 2025), with a 400M-param built-in vision encoder.
- **Vision encoder**: also initialized from Gemma3, follows the **MEM video history encoder design** (temporal + spatial compression over history observations, fixed-size token output regardless of frame count).
- **Action expert**: 860M flow-matching transformer. Attends to all VLM activations but with **stop-gradient** — uses the **Knowledge Insulation (KI) training recipe** (the VLM is supervised separately with FAST tokens, so its representations stay stable while the action expert trains).
- **Lineage**: π0 → π0.5 → π0.6 → π0.6-MEM → π0.7. π0.5 was the first to use intermediate-subtask conditioning; π0.6 added a larger backbone + more diverse conditioning; π0.6-MEM added the memory/history encoder; π0.7 extends with full multimodal-context conditioning.

### Diversified prompt (paper §V)

The "context" `C_t` for each training example now includes:

| Component | Symbol | Purpose | Test-time |
|---|---|---|---|
| **Overall task description** | `ℓ_t` | Conventional high-level instruction ("clean the kitchen") | Always provided |
| **Subtask instruction** | `ℓ̂_t` | Step-by-step semantic subtask ("open the fridge door") | From human or learned high-level policy; can be omitted |
| **Subgoal images** | `g_t = [G^1_t, …, G^n_t]` | Multi-view desired near-future scene; generated by world model `g_ψ` | Generated by lightweight world model at inference; trained dropout 75% |
| **Episode metadata** | `m` | Overall speed (500-step bins), quality (1–5), mistake labels | Prompt with "high speed, high quality, no mistakes" at test time; dropout 15% all, 5% individual |
| **Control mode** | `c ∈ {joint, ee}` | Joint-level vs end-effector actions | Picked per task; no dropout |

### Subgoal-image world model `g_ψ` (paper §V-B)

- Generates desired near-future frames from current observation + subtask instruction + metadata.
- Trained with the standard conditional flow-matching loss `L_CFM` on segments with high-quality subtask labels.
- **Initialized from [BAGEL 14B](https://arxiv.org/abs/2505.14683)** — a mixture-of-transformers image-gen + editing model with web-scale pretraining.
- Web pretraining + non-robot data (egocentric human video) flow into π0.7 via the generated subgoal images.

### Training data (paper §VI-A)

Heterogeneous mixture:
- Demonstration data across many robot platforms (static + mobile, single-arm + bimanual) in diverse environments (lab, home-like, in-the-wild homes).
- **Autonomous rollouts** from policy evaluations (including failures).
- Human interventions inside policy rollouts.
- Open-source robot datasets.
- Egocentric human video.
- Auxiliary non-robot web data (object localization, attribute prediction, VQA, text-only).

### Demonstrated capabilities

1. **Out-of-the-box dexterity**: espresso machine, laundry folding, taking out trash bag, folding a box, peeling vegetables — **no task-specific post-training**.
2. **Instruction generalization**: follows diverse open-ended commands in unseen kitchens / bedrooms.
3. **Zero-shot cross-embodiment**: t-shirt folding transfers to a robot never trained on laundry — matches first-attempt expert teleoperator performance.
4. **Compositional generalization**: prompt-driven new tasks composed from training skills (e.g., loading sweet potato into air fryer when neither appeared in training).

### Comparison framing

Paper claims π0.7's compositional generalization is the **VLA equivalent of the "emergent capabilities"** language models exhibit — a property prior VLAs (including π0) lacked. The synergy between **diverse data + detailed contexts** is the load-bearing finding from ablation studies.

## Why this matters

1. **First credible "emergent capabilities" claim for a VLA**, framed in the same way LLM-side compositional generalization is described. If the result holds up, it shifts the VLA conversation from "can we get any cross-embodiment policy to work" to "can we get policies to recompose skills the way LLMs do."
2. **The multimodal-context-conditioning recipe is the contribution**, not a new architecture. π0.7 = π0.6-MEM + prompt expansion + dropout-during-training to make every context component optional at test time. This is a recipe other VLAs can adopt.
3. **Subgoal-image generation as a substrate for transfer** — using a web-pretrained image generator to produce subgoal images is how π0.7 imports non-robot knowledge into the policy. The world model + policy stack design (with separate models, not a single end-to-end stack) contrasts with JEPA-style integrated approaches.
4. **Production-readiness signals**: "espresso machine out-of-the-box," "matches RL-fine-tuned models without RL fine-tuning," and the [π*0.6 RECAP sibling paper](pistar06-paper.md) (which runs the same hardware for 13 hours straight making espresso) together mark the first time Physical Intelligence has published evidence of multi-hour autonomous deployment of their VLA.
