## Summary

A **community hub / landing page for Core War**: a concise definition of the game, pointers to learning materials, the **[pMARS](pmars-koth.md)** simulator, online tournament **hills**, and community channels. Useful as a present-day entry point and confirmation that Core War remains an active hobby, but it carries **little new technical content** beyond the primary [Dewdney column](dewdney-1984-core-war-scientific-american.md).

## Key claims / facts

- **Definition.** Core War is "a programming game in which two or more programs run in a simulated computer," the goal being to eliminate opponents while staying active. Programs ("**Warriors**") are written in **Redcode**.
- **Simulator.** Directs players to **pMARS** (DOS / UNIX / Windows builds) via the pMARS homepage.
- **Competitive play.** **Corewars Hills** are ongoing **online tournaments** (King-of-the-Hill format) for global competition; a competitions page lists active hills.
- **Community.** Links page to other Core War sites; the **`rec.games.corewars`** newsgroup as the discussion forum. Webmaster credited as "SB" (Sapan Bhatia).
