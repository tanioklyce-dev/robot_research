## Summary
Product page for Reachy 2, Pollen Robotics' open-source bimanual mobile manipulator. "The first open-source humanoid robot specifically designed for the development of embodied AI and real-world applications." Multiple variants from single-arm stationary to dual-arm + mobile base.

## Key specs
- Arms: 7 DOF each; human-arm proportions
- Payload: 3 kg per arm
- Mobile base: three omniwheels + LiDAR + multiple navigation sensors

## Variants
1. Dual Arm + Mobile Base
2. Single Arm + Mobile Base
3. Dual Arm (stationary)
4. Single Arm (stationary)

## Software
- Python SDK
- ROS 2 Humble
- VR teleoperation application (with camera feedback)
- Fully open-source hardware + software
- CPU-powered; AI framework compatible
