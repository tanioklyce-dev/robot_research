# EngineAI T800

**T800** — [EngineAI](engineai.md)'s high-dynamic, heavy-duty flagship humanoid (Terminator-referencing name), released December 2025 and used as the sole platform for the [URKL](../sources/urkl-robot-combat-league.md) combat league.

## Specifications

| Attribute | Value |
|---|---|
| Height | 173 cm |
| Weight | 75 kg |
| Structure | Aerospace/aviation-grade aluminum alloy |
| Joints | Fully self-developed; **450 N·m** peak torque |
| Battery | **World's first solid-state battery** in a humanoid; **4–5 hr** runtime |
| Sensing | 360° LiDAR + stereo cameras |
| Cooling | Active cooling between the leg joints |

Sources: [URKL league coverage](../sources/urkl-robot-combat-league.md), [Shenzhen Story video](../sources/shenzhen-story-urkl-youtube.md).

## Capabilities

Described by EngineAI as "probably the strongest" humanoid: performs **side kicks, aerial kicks, 360-degree aerial rotations, and capoeira-inspired spins** with quick directional changes. The [URKL](../sources/urkl-robot-combat-league.md) framing tests **balance, motion control, and AI** under adversarial real-world load — combat stresses reducers, lead screws, and dexterous-hand tendons.

## History

- Debuted as the **"T-8000" prototype at WRC (World Robot Conference) 2025**.
- **Released December 2025**; mass delivery from EngineAI's Shenzhen manufacturing base (2026).
