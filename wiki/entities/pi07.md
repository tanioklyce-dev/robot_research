**π0.7** — [Physical Intelligence](physical-intelligence.md)'s late-2025 successor to [π0](pi-zero.md) and the intermediate (unreleased-but-referenced) **π0.5 / π0.6 / π0.6-MEM** generations ([paper](../sources/pi07-paper.md)). **5B-param VLA** = **Gemma3 4B VLM backbone** (incl. 400M vision encoder) + **860M flow-matching action expert** + MEM-style video history encoder. The architectural contribution isn't a new module — it's a **diversified prompt** that conditions the model on subtask instructions, **generated subgoal images** (from a separate BAGEL 14B world model), **episode metadata** (speed / quality / mistake labels), and control-mode tags. Each component is randomly dropped during training, so any subset is available at inference.

The headline claim: **first credible "emergent capabilities" in a VLA**. With the diversified-prompt + diverse-data training, π0.7 exhibits **out-of-the-box dexterity** (espresso machine, laundry folding, trash bag, box folding, vegetable peeling), **language-instruction generalization** to unseen kitchens and bedrooms, **zero-shot cross-embodiment transfer** (laundry folding to a robot never trained on it, matching first-attempt expert teleoperator performance), and **compositional task generalization** (loading a sweet potato into an air fryer when neither appeared in training).

## Architecture

| Component | Detail |
|---|---|
| Total params | **5B** |
| VLM backbone | **Gemma3 4B** (Google, 2025) — 4B params + 400M built-in vision encoder |
| Vision encoder | **MEM-style video history encoder** — temporal + spatial compression of history observations, fixed-size token output |
| Action expert | **860M flow-matching transformer**, attends to all VLM activations |
| Training recipe | **[Knowledge Insulation (KI)](../concepts/learning/knowledge-insulation.md)** — VLM supervised via [FAST](fast-action-tokenization.md) tokens; action expert has **stop-gradient** (no gradient flow back to VLM) |
| Subgoal-image world model | **BAGEL 14B** mixture-of-transformers (image-gen + editing), pretrained on web; trained with conditional flow-matching loss on high-quality subtask segments |

## The diversified prompt

| Context component | Symbol | Source at inference | Training dropout |
|---|---|---|---|
| Task description | `ℓ_t` | Always provided | None |
| Subtask instruction | `ℓ̂_t` | Human or learned high-level policy | (none — but can be omitted manually) |
| Subgoal images (multi-view) | `g_t` | Generated by world model `g_ψ` (BAGEL) | **75%** (so model also trains without them) |
| Episode metadata | `m` | Prompt with "high speed, high quality, no mistakes" | **15% all-drop + 5% per-component** |
| Control mode | `c ∈ {joint, ee}` | Picked per task | None |

## Training data

- Demonstration data across many robot platforms (static + mobile, single-arm + bimanual), diverse environments (lab + home-like + in-the-wild homes).
- **Autonomous rollouts** from prior model evaluations (including failures).
- Human interventions inside policy rollouts.
- Open-source robot datasets.
- **Egocentric human video**.
- Auxiliary non-robot web data (object localization, attribute prediction, VQA, text-only).

The diversified prompt is what makes mixing all of this work — without it, the model averages incompatible modes.

## Lineage

```
π0  →  π0.5  →  π0.6  →  π0.6-MEM  →  π0.7
                                  ↘   π*0.6  (RL variant)
```

- **[π0](pi-zero.md)** (2024) — flow-matching action expert on PaliGemma; cross-embodiment dexterity.
- **π0.5** — adds intermediate-subtask conditioning (not separately ingested).
- **π0.6** — larger backbone + more diverse conditioning (not separately ingested).
- **π0.6-MEM** — adds the video history / MEM encoder (not separately ingested).
- **π0.7** — adds multimodal context conditioning (this entity).
- **[π*0.6](pistar06.md)** — sibling RL variant of π0.6 with RECAP recipe.

## Why it matters in this wiki

1. **First VLA with credible emergent capabilities.** The claim parallels LLM-side compositional generalization; if it holds, the VLA conversation shifts from "can we get cross-embodiment to work" to "can policies recompose skills the way LLMs do."
2. **The multimodal-context-conditioning recipe is the contribution, not a new architecture.** Other VLAs can adopt subgoal-images + metadata + dropout-during-training without rewriting their backbone.
3. **Subgoal-image generation as a substrate for transfer.** The world-model-feeds-policy stack design (separate models, not end-to-end) contrasts with JEPA-style integrated approaches.
4. **The combined π0.7 + [π*0.6](pistar06.md) story** = Physical Intelligence's late-2025 push: π0.7 says "scale data + prompts," π*0.6 says "iterate on deployment experience." Both run the same Gemma3-class VLM + flow-matching action expert + KI training.
