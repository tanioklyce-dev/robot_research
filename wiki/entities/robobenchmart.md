**RoboBenchMart** — open simulated dark-store benchmark on [ManiSkill3](maniskill.md) using a Fetch robot. Fine-tuned Octo, π0 and π0.5 all scored zero on multi-step tasks ([paper](../sources/robobenchmart-paper.md)). Code is at [emb-ai/RoboBenchMart](https://github.com/emb-ai/RoboBenchMart).
