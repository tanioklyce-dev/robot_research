# Arcade Learning Environment (ALE)

Framework that allows researchers and hobbyists to develop AI agents for Atari 2600 ROMs. Built on the Stella emulator.

## Core purpose
Evaluation platform for general AI agents. Foundational paper: "The Arcade Learning Environment: An Evaluation Platform for General Agents," Journal of Artificial Intelligence Research.

## Supported environments
- 100+ single-agent Atari games (Breakout, Pac-Man, Space Invaders, Donkey Kong, Frogger, etc.)
- 23 multi-agent environments (Basketball Pong, Joust, Warlords, etc.) — competitive and cooperative

## API / interfaces
- Gymnasium API (recommended modern interface)
- Python interface
- C++ interface
- Visualization tool for debugging and analysis

## Key features
- Separates emulation details from agent design
- Gymnasium-compatible
- Vector environment support
- Customizable rendering modes

## Organization
Maintained by the Farama Foundation. Open-source.
