# Reachy 2 — Open-Source Humanoid Robot

"The first open-source humanoid robot specifically designed for the development of embodied AI and real-world applications." Bimanual mobile manipulator for AI and robotics research.

## Specs
- Arms: 7 DOF each; dimensions/proportions similar to adult human arm
- Payload: 3 kg per arm, dexterous manipulation
- Mobile base: three omniwheels + LiDAR + multiple sensors for navigation

## Variants
1. Reachy 2 Dual Arm + Mobile Base
2. Reachy 2 Single Arm + Mobile Base
3. Reachy 2 Dual Arm (stationary)
4. Reachy 2 Single Arm (stationary)

## Software
- Python SDK for direct control
- ROS 2 Humble compatible
- VR teleoperation application with camera feedback
- CPU-powered, supports modern AI frameworks
- Fully open-source design

## Features
- Remote VR control with camera feedback
- Real-world object manipulation and grasping
- Machine learning integration
- Open-source hardware and software
