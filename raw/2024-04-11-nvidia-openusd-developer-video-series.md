# New Video Series: OpenUSD for Developers

NVIDIA announces an exclusive video series introducing Universal Scene Description (OpenUSD), described as "an open and extensible framework for creating, editing, querying, rendering, collaborating, and simulating within 3D worlds."

## Origin & significance

Pixar Animation Studios invented USD. It is more than a file format — it functions as an ecosystem for modeling and combining diverse data sources. Adoption spans manufacturing, robotics, retail, and architecture.

## Four key USD features highlighted

### 1. Composition and Layering
The composition engine enables "sparse, nondestructive assembly of data from multiple different sources as individual layers," allowing collaborative edits while preserving full data accessibility.

### 2. Custom Schemas
Beyond geometry and shading, NVIDIA collaborated with Pixar and Apple to develop physics schemas for rigid bodies, expanding virtual environment standards.

### 3. Data Source Interoperability
USD storage operates independently from specific filesystems and supports procedural generation through plug-in systems, asset resolvers, and format support (Alembic, OBJ).

### 4. Hydra Pipeline
A generalized scene graph processor that offers flexibility through customizable runtime interfaces (render delegates) without coupling to specific data layouts. Enables pluggable rendering backends.

## Related initiatives

NVIDIA Omniverse provides developer integration tools for incorporating USD into existing workflows and generative AI applications.
