# myBuddy 280 — Dual-Arm Collaborative Robot

## Overview
Dual-arm collaborative humanoid robot for research, education, and creative robotics. Two 6-axis arms + 1 torso axis = 13 DOF total.

## Specs
- DOF: 13 (6 per arm + 1 torso)
- Working radius: 280mm per arm
- Payload: 250g per arm
- Positioning accuracy: ±0.5mm
- Weight: 2.75 kg
- Joint speed: 160°/s max
- Power: DC 24V
- Operating temperature: -5°C to 45°C

## Price
- myBuddy: $1,619 (from $1,699)
- myBuddy + G Shape Base: $1,678

## Features
- 7-inch touchscreen display
- Dual 2MP HD cameras
- Raspberry Pi 4B master controller + ESP32 auxiliary
- 3.3V I/O ports, LEGO-compatible connections
- Multiple end effectors (suction pumps, grippers)

## Software
- Python programming; Windows/Linux/macOS
- ROS1 with built-in RViz and MoveIt
- myBlockly, myStudio
- Serial and TCP/IP protocols
- Open-source URDF files

## Use cases
- AI/vision tasks (object/QR recognition, face/body detection)
- Dual-arm motion planning research
- Interference avoidance algorithms
- Grasping automation
- HRI studies
- Educational projects
